# План: Переиспользуемый компонент FormSheet для редактирования данных

## Контекст

Проект использует:
- **Next.js** с App Router
- **TypeScript**
- **shadcn/ui** компоненты на базе **Radix UI**
- **Tailwind CSS** для стилизации
- **Zod** для валидации (уже установлен)

Уже существующие компоненты:
- `EditSheet` - базовый компонент обертки Sheet с заголовком и кнопками
- `Field`, `FieldLabel`, `FieldDescription`, `FieldError` - компоненты для форм
- `Input`, `Label` - базовые инпуты

## Требования (из ответов пользователя)

1. **Контролируемые компоненты** (value/onChange)
2. **Интеграция с Zod** для валидации схем
3. **Гибкость** для разных структур данных

### 2. Создать `FormSheet` (`/packages/ui/src/components/form-sheet.tsx`)

Компонент на базе улучшенного `EditSheet` с интегрированными полями формы:

**Props:**
```tsx
interface FormSheetProps<T extends z.ZodTypeAny> {
  trigger: ReactNode
  title: string
  description?: string
  schema: T
  defaultValues?: z.infer<T>
  onSubmit: (values: z.infer<T>) => Promise<void> | void
  isOpen?: boolean
  onOpenChange?: (open: boolean) => void
  side?: "top" | "right" | "bottom" | "left"
}
```

**Интеграция:**
- Использование `zod` для валидации
- Контролируемые поля через context или props
- Отображение ошибок валидации
- Состояние `isLoading` во время сохранения

### 3. Создать `FormSheetContext` (`/packages/ui/src/components/form-sheet-context.tsx`)

Контекст для передачи данных между `FormSheet` и полями формы:

```tsx
interface FormSheetContextValue {
  register: (name: string, schema: z.ZodTypeAny) => void
  unregister: (name: string) => void
  getValue: (name: string) => any
  setValue: (name: string, value: any) => void
  errors: Record<string, string>
}
```

### 4. Создать `FormSheetField` (`/packages/ui/src/components/form-sheet-field.tsx`)

Компонент для автоматической регистрации полей в форме:

```tsx
interface FormSheetFieldProps {
  name: string
  label?: string
  description?: string
  children: (props: {
    value: any
    onChange: (value: any) => void
    error?: string
  }) => ReactNode
}
```

### 5. Экспорт компонентов

Обновить `/packages/ui/src/components/index.ts` (или соответствующий файл экспорта):

## Использование

### Базовый пример:

```tsx
import { FormSheet, FormSheetField } from "@workspace/ui/components/form-sheet"
import { z } from "zod"

const userSchema = z.object({
  name: z.string().min(2, "Имя должно содержать минимум 2 символа"),
  email: z.string().email("Некорректный email"),
})

export function EditUser({ user, onSave }) {
  return (
    <FormSheet
      trigger={<Button>Редактировать</Button>}
      title="Редактирование пользователя"
      schema={userSchema}
      defaultValues={{ name: user.name, email: user.email }}
      onSubmit={async (values) => {
        await onSave(values)
      }}
    >
      <FormSheetField name="name" label="Имя">
        {({ value, onChange, error }) => (
          <>
            <Input value={value} onChange={onChange} />
            {error && <span className="text-destructive">{error}</span>}
          </>
        )}
      </FormSheetField>
      
      <FormSheetField name="email" label="Email">
        {({ value, onChange, error }) => (
          <Input value={value} onChange={onChange} />
        )}
      </FormSheetField>
    </FormSheet>
  )
}
```

### Пример с кастомным полем:

```tsx
<FormSheetField name="status" label="Статус">
  {({ value, onChange, error }) => (
    <Select value={value} onValueChange={onChange}>
      <SelectItem value="active">Активен</SelectItem>
      <SelectItem value="inactive">Неактивен</SelectItem>
    </Select>
  )}
</FormSheetField>
```
