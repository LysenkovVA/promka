# Plan: Убрать часовые пояса из дат

## Проблема
JavaScript `Date` объекты всегда содержат временную зону. При работе с датами рождения, найма и увольнения сотрудников они включают время и часовой пояс, что приводит к некорректному отображению и обработке.

## Решение
Добавить `.transform()` в Zod схемы для сброса времени и сохранения только даты (год, месяц, день) в локальном времени пользователя.

## Реализация

### 1. Создать утилиту для сброса часового пояса

**Файл:** `apps/web/lib/date/utils.ts` (создать новый)

```typescript
/**
 * Сбрасывает время и часовой пояс в дате, оставляя только дату
 * в локальном времени пользователя
 */
export function stripTimezone(date: Date | undefined): Date | undefined {
  if (!date) return undefined
  
  return new Date(date.getFullYear(), date.getMonth(), date.getDate())
}
```

## Как это работает

1. **На валидации (Zod):** При получении данных из формы/URL, `z.coerce.date()` преобразует строку в `Date` объект, затем `.transform()` сбрасывает часы/минуты/секунды и часовой пояс, оставляя только дату (00:00:00 в локальном времени).

2. **В UI:** При выборе даты в календаре, время также сбрасывается. Отображение через `toLocaleDateString()` показывает только дату без времени.

3. **В API:** При отправке на сервер, дата уже содержит только дату без времени. Prisma корректно обработает `DateTime` поле.

4. **На сервере:** Prisma хранит `DateTime` поля, но так как время = 00:00:00, это фактически дата без часового пояса.
